# django-rtl-admin

**لوحة إدارة Django ثنائية اللغة تعمل كما ينبغي، دون استبدال لوحة إدارة Django.**

يستطيع Django ترجمة لوحة إدارته إلى العربية والعبرية والفارسية وغيرها من اللغات
التي تُكتب من اليمين إلى اليسار. لكن ترجمة التسميات وعكس اتجاه الصفحة لا يكفيان:
فالمسافات المحددة باتجاهَي اليسار واليمين، والمعرّفات التي تجمع أنظمة كتابة مختلفة،
والأرقام الخاصة بكل إعداد محلي تحتاج إلى معالجة مستقلة.

تضيف `django-rtl-admin` إلى لوحة الإدارة الافتراضية أنماطًا تراعي اتجاه النص،
وأدوات مساعدة للنصوص ثنائية الاتجاه، وتنسيقًا يراعي الإعدادات المحلية، ومبدّلًا للغة.
وتدعم Python 3.10+ وDjango 4.2+ ضمن توليفات Python وDjango المتوافقة.

[تثبيت الحزمة](installation.md) · [البدء السريع](quick-start.md)

استخدم قائمة اختيار اللغة لقراءة الصفحة الرئيسية ودليل البدء السريع بالإنجليزية.

## المشكلات التي تعالجها

- **تخطيط لا ينعكس بالكامل.** تعالج خصائص CSS المنطقية المسافات المتبقية المحددة
  باليسار واليمين في أدوات الكائنات، وعناصر الإجراءات، ونصوص المساعدة في النماذج
  المحاذاة، وحقول التاريخ والوقت، وأيقونات النماذج المضمّنة، وعناصر أخرى في لوحة
  الإدارة الافتراضية.
- **نصوص مختلطة الاتجاه يصعب قراءتها.** تمنع آليات العزل في Unicode وقواعد CSS
  للنص ثنائي الاتجاه القيمَ من إرباك النص المحيط بها. استخدم العزل الصريح من اليسار
  إلى اليمين (LTR) للمعرّفات، والعزل على مستوى المقاطع للأجزاء اللاتينية أو الأعداد
  التي تتخللها علامات ترقيم داخل نصوص من اليمين إلى اليسار (RTL).
- **أعداد تتجاهل نظام الأرقام الخاص بالإعداد المحلي.** تدعم أدوات التنسيق المساعدة،
  التي يتطلب استخدامها تفعيلًا صريحًا، الأرقام اللاتينية والعربية الهندية والعربية
  الهندية الشرقية، مع استخدام Babel لأنماط CLDR وتنسيق Django كخيار احتياطي.
- **غياب أداة مدمجة لاختيار لغة لوحة الإدارة.** يرسل مبدّل اللغة في ترويسة الصفحة
  وفي صفحة تسجيل الدخول طلب `POST` إلى دالة العرض `set_language` في Django،
  ويحافظ على عنوان URL الحالي.

راجع [عيوب RTL في لوحة الإدارة الافتراضية](rtl-defects.md) لمعرفة السلوك قبل
الإصلاحات وبعدها، وأيّ الإصلاحات يُطبّق تلقائيًا وأيّها يتطلب تفعيلًا صريحًا. تغيّر الحزمة
طريقة العرض، لا القيم المخزنة ولا مخطط قاعدة البيانات ولا معنى المعرّفات.

## ابدأ بخطوات بسيطة

```sh
python -m pip install "django-rtl-admin[babel]"
```

ضع `django_rtl_admin` قبل `django.contrib.admin`، واضبط `LocaleMiddleware`،
وأضف مسارات i18n الخاصة بـ Django. يشرح [دليل البدء السريع](quick-start.md)
خطوات الإعداد كاملةً. Babel اختياري؛ فالحزمة الأساسية تعمل بدونه.

تتكامل أنماط CSS ومبدّل اللغة عبر تجاوز قالب لوحة الإدارة الذي توفّره الحزمة.
لعزل قيم قائمة السجلات باستخدام Unicode، أضف
[BidiSafeAdminMixin](admin-mixin.md) صراحةً إلى فئات الإدارة لديك. استخدم
[مرشحات القوالب](template-tags.md) أو [واجهة Python البرمجية](api.md) حيث تحتاج
إلى مخرجات تراعي الإعدادات المحلية؛ فلا يُعاد تنسيق أعمدة لوحة الإدارة العادية تلقائيًا.
