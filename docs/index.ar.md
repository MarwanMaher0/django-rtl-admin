# django-rtl-admin

**لوحة إدارة Django ثنائية اللغة فعلًا، دون استبدال لوحة Django.**

يستطيع Django ترجمة لوحة إدارته إلى العربية والعبرية والفارسية وغيرها من اللغات
المكتوبة من اليمين إلى اليسار. لكن ترجمة التسميات وقلب اتجاه الصفحة لا يكفيان:
فالمسافات المحددة باليمين واليسار، والمعرّفات التي تمزج أنظمة كتابة مختلفة،
والأرقام الخاصة بالإعدادات المحلية تحتاج إلى معالجة مستقلة.

تضيف `django-rtl-admin` أنماطًا تراعي الاتجاه، وأدوات للنصوص ثنائية الاتجاه،
وتنسيقًا يراعي الإعدادات المحلية، ومبدّل لغة إلى لوحة الإدارة الافتراضية.
وتدعم Python 3.10+ وDjango 4.2+ ضمن توليفات Python وDjango المتوافقة.

[تثبيت الحزمة](installation.md) · [البدء السريع](quick-start.md) · [العرض التجريبي المباشر والنشر](deployment.md)

استخدم محدّد اللغة لقراءة أدلة الاستخدام والمرجع بالعربية. تبقى واجهة Python
البرمجية وسجل التغييرات باللغة الإنجليزية.

## ما الذي تصلحه الحزمة { #what-it-fixes }

- **تخطيط لا ينعكس إلا جزئيًا.** تعالج خصائص CSS المنطقية المسافات المحددة
  بالاتجاهات المادية التي تبقى في أدوات الكائنات، وعناصر الإجراءات، ونصوص
  المساعدة المحاذاة، وحقول التاريخ والوقت، وأيقونات العناصر المضمّنة، وغيرها
  من عناصر لوحة الإدارة الافتراضية.
- **نصوص مختلطة الاتجاه يصعب قراءتها.** تمنع محارف العزل في Unicode وقواعد
  الاتجاه في CSS القيم من التأثير في محيطها. استخدم عزل LTR الصريح للمعرّفات،
  وعزل المقاطع للأجزاء اللاتينية أو الأرقام التي تتضمن علامات ترقيم داخل النص العربي.
- **أرقام تتجاهل نظام الترقيم المحلي.** تدعم أدوات التنسيق الاختيارية الأرقام
  اللاتينية والعربية الهندية والعربية الهندية الشرقية، باستخدام Babel لأنماط
  CLDR وتنسيق Django بوصفه بديلًا.
- **غياب محدّد لغة مدمج للوحة الإدارة.** يرسل المبدّل في الترويسة وصفحة تسجيل
  الدخول الطلب إلى عرض `set_language` في Django، مع الحفاظ على عنوان URL الحالي.

راجع [عيوب RTL في لوحة الإدارة الافتراضية](rtl-defects.md) للاطلاع على السلوك
قبل الإصلاح وبعده، والتمييز بين الإصلاحات التلقائية والاختيارية. تغيّر الحزمة
طريقة العرض، لا القيم المخزنة ولا مخطط قاعدة البيانات ولا معنى المعرّفات.

## ابدأ بخطوات بسيطة { #start-small }

```sh
python -m pip install "django-rtl-admin[babel]"
```

ضع `django_rtl_admin` قبل `django.contrib.admin`، واضبط `LocaleMiddleware`،
وأضف مسارات التدويل في Django. يشرح [البدء السريع](quick-start.md) الإعداد كاملًا.
Babel اختيارية؛ فالحزمة الأساسية تعمل بدونها.

تتكامل CSS ومبدّل اللغة عبر القالب الذي تستبدله الحزمة في لوحة الإدارة.
لعزل قيم قائمة السجلات بمحارف Unicode، أضف
[BidiSafeAdminMixin](admin-mixin.md) صراحةً إلى فئات الإدارة.
استخدم [مرشحات القوالب](template-tags.md) أو [واجهة Python البرمجية](api.md)
حيث تحتاج إلى مخرجات تراعي الإعدادات المحلية؛ فأعمدة الإدارة العادية لا يُعاد
تنسيقها تلقائيًا.
