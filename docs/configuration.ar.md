# الإعدادات { #configuration }

اضبط الحزمة عبر قاموس `RTL_ADMIN` في إعدادات Django.
كل مفتاح اختياري؛ وتحتفظ المفاتيح غير المحددة بقيمها الافتراضية. ابدأ بدليلَي
[التثبيت](installation.md) و[البدء السريع](quick-start.md) قبل تغيير
الميزات منفردةً.

```python
RTL_ADMIN = {
    "CURRENCY": "EGP",
    "LANGUAGE_SWITCHER_LABELS": "both",
}
```

## المرجع الكامل للإعدادات { #complete-settings-reference }

هذه جميع المفاتيح الثلاثة عشر المدعومة، والمُعرّفة في `django_rtl_admin.conf.DEFAULTS`.

| المفتاح | القيمة الافتراضية | التأثير |
| --- | --- | --- |
| `ENABLE_CSS` | `True` | إخراج رابط ورقة أنماط الحزمة وأي تجاوز خط مضمّن عبر `rtl_admin_styles`. |
| `FONT_STACK` | `None` | تجاوز `--rtl-admin-font-stack` بسلسلة نصية أو تسلسل من أسماء عائلات الخطوط؛ وتُبقي `None` مجموعة الخطوط المرفقة. |
| `EXTRA_RTL_LANGUAGES` | `()` | إضافة رموز لغات إلى اللغات ذات الاتجاه من اليمين إلى اليسار الموجودة أصلًا في `LANGUAGES_BIDI` في Django. |
| `ISOLATION_DIRECTION` | `"auto"` | العزل الافتراضي للقيمة كاملةً: `"auto"` ‏(FSI)، أو `"ltr"` ‏(LRI)، أو `"rtl"` ‏(RLI). |
| `ISOLATE_CHANGELIST` | `True` | تفعيل العزل في فئات الإدارة التي تستخدم `BidiSafeAdminMixin` صراحةً، ما لم يُتجاوز الإعداد لكل فئة إدارة على حدة. |
| `ISOLATE_TABLE_CELLS` | `True` | إضافة فئة لعنصر body تفعّل عزل CSS لخلايا قائمة السجلات وحاويات التنقل والبيانات المرتبطة بها. |
| `PLAINTEXT_FORM_FIELDS` | `True` | إضافة فئة لعنصر body تفعّل اتجاه النص العادي المستند إلى أول محرف قوي للمدخلات الشبيهة بالنص ومساحات النص. |
| `NUMERALS` | `"auto"` | اتباع نظام الترقيم في الإعدادات المحلية، أو فرض `"latn"` أو `"arab"` أو `"arabext"` في دوال التنسيق المساعدة. |
| `USE_BABEL` | `True` | استخدام Babel عند تثبيته؛ وإلا تُعرض الأعداد من جداول CLDR المضمّنة، مع اللجوء إلى Django كحل أخير. |
| `CURRENCY` | `"USD"` | العملة الافتراضية لـ `format_currency` و`l10n_currency` عند عدم تمرير وسيطة عملة تُقيّم على أنها صحيحة منطقيًا. |
| `LANGUAGE_SWITCHER` | `True` | تفعيل نموذج المبدّل، وبرنامجه النصي للتحسين التدريجي، والفحصين W003/W004. |
| `LANGUAGE_SWITCHER_LANGUAGES` | `None` | استخدام `settings.LANGUAGES`، أو تقديم تسلسل من الرموز أو أزواج `(code, label)`. |
| `LANGUAGE_SWITCHER_LABELS` | `"native"` | اختيار التسميات باللغة الأم، أو التسميات المضبوطة/الإنجليزية باستخدام `"translated"`، أو كلتيهما باستخدام `"both"`. |

## الأنماط والاتجاه { #styling-and-direction }

يمنع `ENABLE_CSS=False` إخراج كلٍّ من رابط ورقة الأنماط وتجاوز `FONT_STACK`.
ولا يعطّل عزل Unicode أو التنسيق أو إخراج فئات عنصر body
أو برنامج المبدّل النصي. وتظل أنماط لوحة إدارة Django القائمة مستقلةً.

ينطبق `FONT_STACK` على عناصر body ذات الاتجاه من اليمين إلى اليسار ومدخلاتها ومساحات النص
وقوائم الاختيار والأزرار فيها. يحوّله الوسم إلى قائمة CSS من نوع `font-family` داخل عنصر
`<style>`:

- تُفسّر السلسلة النصية بوصفها قائمة عائلات خطوط في CSS، مثل
  `'"Noto Naskh Arabic", Tahoma, serif'`. يمكن أن تتضمن الأسماء غير المحاطة بعلامات اقتباس مسافات؛
  أما علامة الاقتباس أو الشرطة المائلة العكسية، فيجب أن تكون داخل اسم محاط بعلامات اقتباس.
- يحتوي التسلسل على اسم عائلة خطوط واحد في كل عنصر، إما بصيغته الخام (`"Noto Naskh Arabic"`) أو
  محاطًا بعلامات اقتباس مسبقًا (`'"Noto Naskh Arabic"'`). ويُعدّ العنصر الذي يحتوي على فاصلة
  اسمًا واحدًا.
- يُخرج كل اسم عائلة خطوط كسلسلة نصية في CSS محاطة بعلامتَي اقتباس مزدوجتين، مع تهريب `\` و`"`.
  وتبقى الكلمات المفتاحية العامة (`serif` و`sans-serif` و`monospace` و`cursive`
  و`fantasy` و`system-ui` و`ui-serif` و`ui-sans-serif` و`ui-monospace`
  و`ui-rounded` و`math` و`emoji` و`fangsong`) والكلمتان المفتاحيتان لخطوط النظام `-apple-system` و
  `BlinkMacSystemFont` دون علامات اقتباس، ما لم تضعها أنت بين علامات اقتباس.

```python
RTL_ADMIN = {
    "FONT_STACK": ("Noto Naskh Arabic", "Tahoma", "sans-serif"),
    "EXTRA_RTL_LANGUAGES": ("tzm",),
}
```

ينتج عن ذلك
`:root { --rtl-admin-font-stack: "Noto Naskh Arabic", "Tahoma", sans-serif; }`،
وكذلك عن السلسلة النصية `'"Noto Naskh Arabic", Tahoma, sans-serif'`.

لا تُخرج القيم التي تُقيّم على أنها خاطئة منطقيًا أي تجاوز. وقد تؤدي قيمة غير سليمة، مثل
علامة اقتباس غير مغلقة، أو اسم عائلة خطوط يتضمن `<` أو `>` أو `{` أو `}` أو `;` أو محرف
تحكم، إلى إغلاق عنصر `<style>` أو قاعدة CSS. عندئذٍ يتخطى الوسم
التجاوز، ويسجّل تحذيرًا عبر المسجّل `django_rtl_admin`، وتُطبّق
مجموعة الخطوط المرفقة.

تؤثر اللغات الإضافية ذات الاتجاه من اليمين إلى اليسار في وسم الاتجاه وفئات عنصر body وخاصية
`dir` لخيارات المبدّل والاتجاه الأساسي الافتراضي لـ `bidi_runs`. كما يقرأ اكتشاف الاتجاه
`LANGUAGES_BIDI` في Django باستخدام مطابقة رمز اللغة الأساسي نفسها التي يستخدمها
`get_language_bidi()`، لذا يحصل أي رمز يُضاف إلى `LANGUAGES_BIDI` على فئات
`rtl-admin--rtl` المطابقة لعنصر body. وتؤدي الرموز الموجودة في `EXTRA_RTL_LANGUAGES` والغائبة
عن `LANGUAGES_BIDI` إلى إطلاق `rtl_admin.W006`: إذ يُبقي Django اتجاه `<html dir>`
من اليسار إلى اليمين (LTR)، بينما تجعل الحزمة اتجاه body من اليمين إلى اليسار (RTL). يُفضّل استخدام رموز بأحرف صغيرة
تفصل بينها شرطات؛ ويمكن للرموز الإقليمية أن ترث اتجاه لغتها الأساسية. ولا تضيف هذه الإعدادات
لغات إلى `LANGUAGES`، ولا تثبّت ترجمات، ولا تغيّر بيانات Babel.
توفّر ورقة الأنماط اتجاه body للغات الإضافية؛ ولا تعيد كتابة
خاصية `<html dir>` في Django. راجع [فحوصات النظام](system-checks.md#rtl_adminw006-extra-rtl-language-missing-from-languages_bidi).

يتحكم `ISOLATE_TABLE_CELLS` في تطبيق `unicode-bidi: isolate` على خلايا جسم قائمة السجلات،
وخلايا النماذج المضمّنة الجدولية، ومسار التنقل، وعناوين المحتوى، وروابط أدوات الكائنات،
وروابط مرشّحات قائمة السجلات. ويعمل في كلا اتجاهَي الواجهة، ولا يُدرج
محارف في القيم.

يتحكم `PLAINTEXT_FORM_FIELDS` في تطبيق `unicode-bidi: plaintext; text-align: start` على
مدخلات النص والبريد الإلكتروني وعناوين URL والبحث والهاتف، والمدخلات التي لا تحتوي على `type`،
ومساحات النص. ويحدّد كل حقل أو فقرة في مساحة النص اتجاهه بنفسه.

ليس هذان الخياران مفتاحَي تعطيل شاملين للنص ثنائي الاتجاه: فطالما كانت ورقة الأنماط
محمّلة، تظل التسميات ونصوص المساعدة والأوصاف والقيم المخصصة للقراءة فقط تتلقى
قواعد النص العادي. كما تحتفظ عناصر URL ومدخلات اسم المستخدم وكلمة المرور وعناصر UUID والشيفرة
بقواعدها المخصصة للاتجاه من اليسار إلى اليمين والعزل.

## عزل Unicode { #unicode-isolation }

يختار `ISOLATION_DIRECTION` محرف البدء لعزل القيمة كاملةً:

| القيمة | محرف البدء | المعنى |
| --- | --- | --- |
| `"auto"` | FSI, U+2068 | تحديد الاتجاه من أول محرف قوي. |
| `"ltr"` | LRI, U+2066 | فرض الاتجاه من اليسار إلى اليمين داخل نطاق العزل. |
| `"rtl"` | RLI, U+2067 | فرض الاتجاه من اليمين إلى اليسار داخل نطاق العزل. |

تنتهي الخيارات الثلاثة جميعًا بـ PDI, U+2069. وتستخدم القيمة الافتراضية في `bidi_isolate`،
وعمليات الوصل المعزولة، والجزء بين القوسين من تسميات اللغات عند استخدام `"both"`، وأغلفة المزيج
التي لا يُحدد لها اتجاه لكل فئة إدارة على حدة. أما `bidi_runs`، فيستخدم افتراضيًا
اتجاه اللغة النشطة.

لا يؤثر `ISOLATE_CHANGELIST` في `ModelAdmin` العادي: فعّل الميزة صراحةً باستخدام
[مزيج لوحة الإدارة](admin-mixin.md). وتتجاوز خاصيته `bidi_isolate_changelist`
الخيار العام. عزل CSS وعزل Unicode مستقلان، لذا
لا يؤدي تعطيل أحدهما إلى تعطيل الآخر.

## الأعداد والعملات وBabel { #numbers-currencies-and-babel }

يختار `NUMERALS` أشكال الأرقام التالية:

| القيمة | الأرقام |
| --- | --- |
| `"latn"` | `0123456789` |
| `"arab"` | `٠١٢٣٤٥٦٧٨٩` |
| `"arabext"` | `۰۱۲۳۴۵۶۷۸۹` |

عند استخدام `"auto"`، تستخدم الدوال المساعدة القيمة الافتراضية للإعدادات المحلية في Babel عندما تشير
إلى نظام ترقيم مدعوم. وإذا كان اسم النظام في Babel غير فارغ لكنه غير مدعوم، تُختار الأرقام
اللاتينية. وفي غياب إعدادات Babel المحلية أو القيمة الافتراضية لنظام الترقيم فيها، تستخدم الدوال
المساعدة خريطة القيم البديلة للحزمة. يستخدم الرمز `ar` وحده الأرقام اللاتينية، ويستخدم `ar-eg`
الأرقام العربية الهندية، ويستخدم `fa` الأرقام العربية الهندية الموسّعة.

يؤدي فرض قيمة `NUMERALS` إلى تغيير محارف الأرقام، وليس كل فاصل أو نمط
عملة. يتخطى `USE_BABEL=False` استخدام Babel حتى عند تثبيته، وينطبق
السلوك نفسه عند غياب Babel: عندئذٍ تُعرض الأعداد من جداول CLDR
المضمّنة في الحزمة — مع تحويل الأرقام والفواصل والتجميع نفسها المستخدمة
مع Babel — ولا يُلجأ إلى Django مع تحويل أشكال الأرقام إلا للإعدادات المحلية
التي لا تغطيها تلك الجداول. التنسيق البديل للعملات هو عدد بمنزلتين عشريتين،
ومسافة غير قابلة للكسر، ورمز العملة؛ أما التنسيق البديل للنسب المئوية، فيستخدم
نسبة مئوية مقربة إلى عدد صحيح. يستخدم تنسيق التاريخ والوقت دون Babel دائمًا Django؛ وترد التفاصيل
في [واجهة Python البرمجية](api.md).

تؤثر هذه الإعدادات في دوال التنسيق المساعدة الصريحة و[المرشّحات](template-tags.md)،
لا في كل حقل في لوحة الإدارة. ويستخدم المزيج تنسيق عرض الحقول المعتاد في Django.

## مبدّل اللغة { #language-switcher }

اضبط لغات Django المتاحة أولًا؛ إذ تتحكم القائمة المخصصة للمبدّل فقط
في الصفوف التي يعرضها. تُقبل العناصر التي تحتوي على رموز فقط، وكذلك أزواج `(code, label)`:

```python
LANGUAGES = [("en", "English"), ("ar-eg", "Arabic (Egypt)")]
RTL_ADMIN = {
    "LANGUAGE_SWITCHER_LANGUAGES": ["en", ("ar-eg", "Arabic (Egypt)")],
    "LANGUAGE_SWITCHER_LABELS": "both",
}
```

تستخدم `None` قائمة `LANGUAGES`؛ ولا يتيح التسلسل الفارغ أي لغات. ويُحافظ على الترتيب.
يُخفى النموذج عند تعطيله، أو عند وجود أقل من صفَّين، أو عندما
يتعذر توليد عنوان `set_language` عكسيًا ويُرفع `NoReverseMatch`. ولا يؤدي غياب البرمجيات الوسيطة
إلى إخفائه. اتبع [البدء السريع](quick-start.md) لضبط نقطة النهاية والبرمجيات الوسيطة.

تُختار التسميات كما يلي:

- `"native"`: اسم اللغة بلغتها المحلية في Django، مع الرجوع إلى اسمها أو رمزها عند الحاجة؛
  وتُتجاهل التسميات المضبوطة للرموز المعروفة.
- `"translated"`: التسمية المضبوطة، وإلا قيمة `name` الإنجليزية في Django أو رمز اللغة.
  لا تُترجم السلاسل النصية العادية تلقائيًا؛ استخدم تسميات ذات ترجمة مؤجلة
  عند الحاجة.
- `"both"`: التسمية باللغة الأم، مع تسمية مضبوطة/إنجليزية معزولة بين قوسين، ما لم
  تتساوَ التسميتان. تستخدم الرموز غير المعروفة تسميتها المضبوطة أو رمزها.

يمنع تعطيل `LANGUAGE_SWITCHER` أيضًا إخراج برنامجه النصي وإجراء الفحصين
`rtl_admin.W003`/`rtl_admin.W004`. ويظل الوسم `rtl_admin_language_links` الذي يوفّر
البيانات فقط متاحًا. وعند تفعيل المبدّل، يمكن أن يظل البرنامج النصي والفحصان
نشطين حتى إذا أُخفي النموذج بسبب عدد اللغات أو توجيه عناوين URL.

## التحقق والتجاوزات { #validation-and-overrides }

لا تُطبّق قواعد تحقق صارمة من الخيارات إلا على `ISOLATION_DIRECTION` و`NUMERALS` و`LANGUAGE_SWITCHER_LABELS`؛
وترفع القيم غير الصالحة `ImproperlyConfigured` عند الوصول إليها.
استخدم قيمًا منطقية فعلية للخيارات: فالسلسلة النصية `"False"` تُقيّم على أنها صحيحة منطقيًا. وتُتجاهل المفاتيح غير المعروفة،
ويبلّغ عنها [فحص النظام `rtl_admin.W002`](system-checks.md).

يمكن لمستدعي الواجهة من Python قراءة `rtl_settings.CURRENCY` أو `rtl_settings["CURRENCY"]`
بعد استيراد `rtl_settings` من `django_rtl_admin`. تُخزّن القيم مؤقتًا عند الحاجة.
وتعيد `override_settings` في Django ضبط ذاكرة التخزين المؤقت للكائن الوحيد عند تغيير `RTL_ADMIN`
أو `LANGUAGES` أو `LANGUAGE_CODE`؛ ولا يؤدي تعديل قاموس في موضعه إلى ذلك.
