# وسوم القوالب ومرشحاتها { #template-tags-and-filters }

حمّل المكتبة في كل قالب Django يستخدمها:

```django
{% load rtl_admin %}
```

تحتوي المكتبة على 14 مرشحًا و8 وسوم. تفترض الأمثلة أدناه أن المكتبة محمّلة
وأن المتغيرات تأتي من سياق القالب. تستخدم أمثلة الأرقام قيمًا عددية أو سلاسل نصية
عددية؛ وتستخدم أمثلة التاريخ والوقت كائنات Python من نوع date أو datetime أو time.
راجع [الإعدادات](configuration.md) لمعرفة القيم الافتراضية المشتركة،
و[واجهة Python البرمجية](api.md) للاستخدام خارج القوالب.

## مرشحات النص ثنائي الاتجاه { #bidirectional-text-filters }

### `bidi_isolate` { #bidi_isolate }

يحيط القيمة كاملةً بمحارف عزل Unicode. الاتجاه الاختياري هو `"auto"`
أو `"ltr"` أو `"rtl"`؛ وعند حذفه يُستخدم `ISOLATION_DIRECTION` (وقيمته الافتراضية `"auto"`).
استخدم العزل من اليسار إلى اليمين (LTR) للمعرّفات التي لا يُفسَّر محتواها:

```django
{{ book.isbn|bidi_isolate:"ltr" }}
```

تُعرض `None` والنصوص الفارغة كمخرجات فارغة. تُهرَّب شيفرة HTML العادية عند تفعيل
التهريب التلقائي؛ أما شيفرة HTML المعلَّمة مسبقًا بأنها آمنة فيُوثق بها. يعطّل
`{% autoescape off %}` التهريب. يضيف العزل محارف، لا عنصر HTML، ولا يكشف أغلفة العزل الموجودة.

### `bidi_runs` { #bidi_runs }

يعزل فقط المقاطع المضمّنة ذات الاتجاه المعاكس في النص النثري. الاتجاه الأساسي
الاختياري هو `"ltr"` أو `"rtl"`؛ وعند حذفه يتبع اللغة النشطة، لا
`ISOLATION_DIRECTION`. لسلسلة نصية من السياق مثل `note = "مرحبا v1.0"`:

```django
{{ note|bidi_runs:"rtl" }}
```

في النصوص النثرية من اليمين إلى اليسار (RTL)، تُعزل أيضًا الأرقام التي تتخللها علامات
ترقيم، مثل التواريخ والإصدارات؛ أما الأرقام المجردة فتُترك كما هي. يسبق العزلُ التهريبَ
لتبقى كيانات HTML سليمة. تُعاد السلاسل النصية المعلَّمة مسبقًا بأنها آمنة والكائنات
التي توفّر `__html__` دون تغيير لتجنب إتلاف شيفرة HTML. عند توضيح عزل المقاطع، استخدم
سلسلة نصية عادية من السياق، لا قيمة نصية حرفية آمنة في القالب. تُعرض `None` كمخرجات فارغة.

### `bidi_strip` { #bidi_strip }

يزيل محارف LRI وRLI وFSI وPDI وLRM وRLM التي تستخدمها الحزمة:

```django
{{ reference|bidi_isolate:"ltr"|bidi_strip }}
```

تُعرض `None` كمخرجات فارغة. لا يزيل هذا المرشح جميع محارف التحكم في الاتجاه في Unicode،
وليس أداة لتنقية HTML. تُحفظ حالة المدخلات المعلَّمة بأنها آمنة.

### `bidi_dir` { #bidi_dir }

يعيد `"rtl"` أو `"ltr"` بناءً على أول محرف ذي اتجاه قوي. الاتجاه البديل الاختياري
هو `"ltr"` افتراضيًا؛ وتستخدمه الأرقام وعلامات الترقيم والنصوص الفارغة و`None`:

```django
<span dir="{{ reference|bidi_dir:"rtl" }}">{{ reference }}</span>
```

لا يُتحقق من صحة الاتجاه البديل؛ استخدم `"ltr"` أو `"rtl"`. هذا هو اتجاه المحتوى،
لا اتجاه اللغة النشطة.

## مرشحات التنسيق حسب الإعدادات المحلية { #locale-aware-formatting-filters }

تستخدم هذه المرشحات اللغة النشطة و`NUMERALS` و`USE_BABEL`. لاختيار لغة لكتلة،
حمّل `i18n` أيضًا واستخدم وسم Django المسمّى `{% language %}`.
لا يضيف التنسيق بحد ذاته محارف عزل Unicode؛ أتبعه بالمرشح `bidi_isolate` عند الحاجة.
وكمرشحات Django المضمّنة، تتعامل هذه المرشحات مع الإخفاق دون إثارة استثناءات:
تعيد المرشحات العددية المدخلات غير العددية أو غير المنتهية كنص، وتُعرض التواريخ
والأوقات غير الصالحة كمخرجات فارغة، ويُتجاهل وسيط المنازل العشرية غير السليم.
تُطبَّع السلاسل النصية العددية قبل التنسيق، بما فيها الصيغة الأسّية والمسافات البيضاء
المحيطة بها. أما دالة Python المساعدة `format_currency()` فهي صارمة، وتثير
`ValueError` للمدخلات غير الفارغة أو غير العددية أو غير المنتهية.

### `l10n_number` { #l10n_number }

ينسّق عددًا مع تجميع الخانات واستخدام أرقام الإعدادات المحلية. يحدد الوسيط الاختياري
عدد المنازل العشرية؛ وعند حذفه يُترك تحديد الدقة للآلية الخلفية:

```django
{{ amount|l10n_number:"2" }}
```

عندما تكون `amount = 2.5` واللغة هي الإنجليزية، يُعرض `2.50`. يُتجاهل وسيط الدقة
غير الفارغ إذا لم يكن عددًا صحيحًا. تُعرض `None` أو المدخلات الفارغة كمخرجات فارغة.
يمر النص غير العددي دون تغيير. لا يتيح هذا المرشح وسيطًا للتحكم في تجميع الخانات.

### `l10n_currency` { #l10n_currency }

ينسّق مبلغًا ماليًا باستخدام رمز عملة اختياري؛ والقيمة الافتراضية هي `CURRENCY` (`"USD"`):

```django
{{ book.price|l10n_currency:"EGP" }}
```

يوفّر Babel أنماطًا خاصة بالإعدادات المحلية. تتكون المخرجات البديلة من عدد منسّق
حسب الإعدادات المحلية بمنزلتين عشريتين، ومسافة غير قابلة للكسر، ورمز العملة.
تُعرض `None` أو المدخلات الفارغة كمخرجات فارغة؛ ويستخدم وسيط العملة الفارغ القيمة
الافتراضية المحددة في الإعدادات. تُعرض المدخلات غير العددية دون تغيير بدلًا من إنتاج مبلغ مشوَّه.

### `l10n_percent` { #l10n_percent }

ينسّق نسبةً على هيئة نسبة مئوية، دون وسيط للمرشح:

```django
{{ ratio|l10n_percent }}
```

عندما تكون `ratio = 0.256`، تبدأ المخرجات الإنجليزية بـ`26`. تكون المدخلات عادةً
نسبة ضمن المجال `0..1`، لكن هذا المجال غير مفروض. تضرب آلية Django البديلة القيمة
في 100، وتقرّب إلى عدد صحيح مع تقريب أنصاف الوحدات إلى الأعلى، ثم تلحق `%`.
تُعرض المدخلات الفارغة كمخرجات فارغة؛ وتُعرض المدخلات غير العددية دون تغيير.

### `l10n_date` { #l10n_date }

ينسّق تاريخًا. القيمة الافتراضية لنمط التنسيق الاختياري هي `"medium"`:

```django
{{ book.published_on|l10n_date:"long" }}
```

استخدم `"short"` أو `"medium"` أو `"long"` أو `"full"`. تعتمد الأنماط المخصصة
على الآلية الخلفية. تُعرض `None` وقيم التاريخ غير الصالحة كمخرجات فارغة؛ وتتبع
أشكال الأرقام المحلية الإعداد `NUMERALS`.

### `l10n_datetime` { #l10n_datetime }

ينسّق تاريخًا ووقتًا. القيمة الافتراضية لنمط التنسيق الاختياري هي `"medium"`:

```django
{{ updated_at|l10n_datetime:"short" }}
```

تطابق الأنماط وسلوك الأنماط المخصصة ما يقدمه `l10n_date`. تُعرض `None` وقيم
التاريخ والوقت غير الصالحة كمخرجات فارغة. يُسجَّل كل من `l10n_datetime` و`l10n_time`
مع `expects_localtime=True`، ولذلك يحوّل Django قيم `datetime` المرتبطة بمنطقة زمنية
إلى المنطقة الزمنية النشطة عند تفعيل `USE_TZ`، ويتركها كما هي داخل
`{% localtime off %}` (أو عندما تكون `USE_TZ=False`).

### `l10n_time` { #l10n_time }

ينسّق وقتًا أو تاريخًا ووقتًا. القيمة الافتراضية لنمط التنسيق الاختياري هي `"medium"`:

```django
{{ opening_time|l10n_time:"short" }}
```

يلتزم Babel بالنمط؛ أما آلية Django البديلة فتستخدم دائمًا تنسيق الوقت الخاص
بالإعدادات المحلية، متجاهلةً الوسيط. تُعرض `None` وقيم الوقت غير الصالحة كمخرجات فارغة.

### `local_digits` { #local_digits }

يعيد كتابة أشكال الأرقام في سلسلة نصية منسّقة مسبقًا، دون تغيير علامات الترقيم:

```django
{{ "REF-2024"|local_digits }}
```

عند استخدام الأرقام التلقائية في `ar-eg`، يُعرض `REF-٢٠٢٤`. يتعرف التحويل على
الأرقام اللاتينية والعربية الهندية والعربية الهندية الموسّعة في المدخلات.
تُعرض `None` كمخرجات فارغة؛ ويمر النص غير العددي دون تغيير، وكذلك القيمة الأصلية إذا فشل التحويل.

### الفروق بين الآليات الخلفية { #backend-differences }

دون Babel، يستخدم النمط `"short"` للتاريخ أو التاريخ والوقت تنسيق Django المختصر؛
أما `"medium"` و`"long"` و`"full"` فتستخدم جميعها تنسيقه المعتاد. لا يمكن
استخدام أنماط Babel CLDR المخصصة وسلاسل تنسيق Django بالتبادل. لا تتضمن هذه
المرشحات وسيطًا للغة أو المنطقة الزمنية أو نظام الترقيم؛ استخدم الإعدادات أو تفعيل
اللغة أو [واجهة التنسيق البرمجية في Python](api.md) حسب الحاجة.

## وسوم الاتجاه والملفات الثابتة { #direction-and-asset-tags }

جميع الوسوم، باستثناء `rtl_admin_language_switcher`، وسوم بسيطة وتدعم
`as variable` لحفظ نتيجتها. تتلقى الوسوم التي تستخدم السياق هذا السياق تلقائيًا؛
لا تمرّره كوسيط في القالب.

### `rtl_admin_direction` { #rtl_admin_direction }

يعيد `"rtl"` أو `"ltr"` للغة النشطة، بما في ذلك اللغات الإضافية المكتوبة من اليمين إلى اليسار:

```django
<section dir="{% rtl_admin_direction %}">{{ content }}</section>
```

### `rtl_admin_body_class` { #rtl_admin_body_class }

يعيد فئات عنصر body الخاصة بورقة الأنماط:

```django
<body class="{% rtl_admin_body_class %}">
  {{ content }}
</body>
```

تبدأ النتيجة بـ`rtl-admin rtl-admin--rtl` أو `rtl-admin rtl-admin--ltr`.
ثم تتضمن `rtl-admin--isolate-cells` و`rtl-admin--plaintext-fields`
عند تفعيل إعداداتهما، حتى لو كانت `ENABLE_CSS=False`.

### `rtl_admin_site_name_tag` { #rtl_admin_site_name_tag }

يعيد اسم عنصر الهوية: `h1` قبل Django 5.0، و`div` في الإصدارات الأخرى:

```django
{% rtl_admin_site_name_tag as site_name_tag %}
<{{ site_name_tag }} id="site-name">{{ site_header }}</{{ site_name_tag }}>
```

### `rtl_admin_styles` { #rtl_admin_styles }

يُخرج رابط ورقة الأنماط وأي تخصيص للإعداد `FONT_STACK`:

```django
{% rtl_admin_styles %}
```

تكون المخرجات فارغة عند `ENABLE_CSS=False`. تستخدم عناوين URL معالجة Django
للملفات الثابتة. تُضاف قيمة `csp_nonce` الموفَّرة في السياق إلى عنصر الرابط ووسم
الأنماط الاختياري. تُحوَّل قائمة الخطوط إلى صيغة CSS، ولا تُهرَّب بصيغة HTML؛ راجع
[الإعدادات](configuration.md#styling-and-direction) لمعرفة قواعد علامات الاقتباس
والقيم التي تُتجاوز.

### `rtl_admin_scripts` { #rtl_admin_scripts }

يُخرج سكربت مبدّل اللغة المؤجَّل التنفيذ:

```django
{% rtl_admin_scripts %}
```

تكون المخرجات فارغة عند `LANGUAGE_SWITCHER=False`؛ وإلا فقد تظهر حتى عندما يكون
النموذج مخفيًا بسبب عدد اللغات أو غياب عنوان URL. يستخدم الوسم أيضًا `csp_nonce`
من السياق عند توفره. لا تنشئ الحزمة قيم nonce.

يستدعي القالب الأساسي للوحة الإدارة المرفق مع الحزمة بالفعل وسوم فئات body والأنماط
والسكربت والهوية. استخدم هذه الوسوم منفردةً في القوالب المخصصة بدلًا من تحميل
الملفات مرتين. راجع [التثبيت](installation.md) لمعرفة وراثة القوالب.

## وسوم اللغة والمجموعات { #language-and-collection-tags }

### `rtl_admin_language_switcher` { #rtl_admin_language_switcher }

يعرض نموذج مبدّل اللغة:

```django
{% rtl_admin_language_switcher %}
```

لا يدعم وسم التضمين هذا صيغة `as variable`. لا يعرض شيئًا عند تعطيله، أو عند وجود
أقل من صفَّين للغات، أو عندما يثير توليد عنوان `set_language` الاستثناء
`NoReverseMatch`. لا يؤدي غياب `LocaleMiddleware` إلى إخفاء النموذج.

يرسل النموذج طلب POST يتضمن `language` المختارة ورمز CSRF و`next` إلى `set_language`.
تحتوي `next` على المسار الكامل للطلب الحالي، بما في ذلك سلسلة معاملات الاستعلام،
أو تكون فارغة عند غياب الطلب. استخدم سياق قالب عاديًا يدعم الطلب وCSRF.
ترسل JavaScript النموذج عند تغيير الاختيار وتخفي الزر؛ ودونها يعمل زر الإرسال.
راجع [البدء السريع](quick-start.md) و[فحوصات النظام](system-checks.md).

### `rtl_admin_language_links` { #rtl_admin_language_links }

يعيد بيانات مجردة لاستخدامها في شيفرة HTML مخصصة، لا روابط تشعبية جاهزة:

```django
{% rtl_admin_language_links as languages %}
<ul>
  {% for language in languages %}
    <li lang="{{ language.code }}"
        dir="{% if language.bidi %}rtl{% else %}ltr{% endif %}">
      {{ language.label }}{% if language.is_active %} — active{% endif %}
    </li>
  {% endfor %}
</ul>
```

يحتوي كل قاموس على `code` و`label` و`bidi` و`is_active`؛ ولا يوجد مفتاح لعنوان URL.
يعيد الوسم البيانات حتى عند تعطيل المبدّل أو غياب نقطة نهايته. تُحدَّد اللغة النشطة
بمقارنة الرموز بعد تحويلها إلى أحرف صغيرة مقارنةً تامة، دون الرجوع إلى رمز بديل
للمنطقة. يُحفظ ترتيب اللغات وتكرارها. راجع [الإعدادات](configuration.md)
لمعرفة أنماط تسميات اللغات ومصدر قائمة اللغات.

### `rtl_admin_isolated_join` { #rtl_admin_isolated_join }

يدمج عناصر كائن قابل للتكرار، مع عزل كل قيمة باستخدام `ISOLATION_DIRECTION`:

```django
{% rtl_admin_isolated_join references "; " %}
```

على سبيل المثال، يمكن أن تكون `references` هي `["ISBN-123", "REF-456"]`.
القيمة الافتراضية للفاصل الاختياري هي `", "`. يُعرض الكائن القابل للتكرار الفارغ
أو `None` كمخرجات فارغة؛ مرّر مجموعةً، لا سلسلة نصية، إلا إذا كنت تقصد دمج المحارف
منفردةً. تُهرَّب القيم والفواصل العادية، بينما يُوثق بشيفرة HTML الآمنة. يظل تهريب
القيم مفعّلًا حتى داخل `{% autoescape off %}`. ولا يُعزل الفاصل نفسه.
