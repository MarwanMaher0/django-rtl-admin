# وسوم القوالب ومرشحاتها { #template-tags-and-filters }

حمّل المكتبة في كل قالب Django يستخدمها:

```django
{% load rtl_admin %}
```

تحتوي المكتبة على 23 مرشحًا و9 وسوم. تفترض الأمثلة أدناه أن المكتبة محمّلة
وأن المتغيرات تأتي من سياق القالب. تستخدم أمثلة الأرقام قيمًا عددية أو سلاسل نصية
عددية؛ وتستخدم أمثلة التاريخ والوقت كائنات Python من نوع date أو datetime أو time.
راجع [الإعدادات](configuration.md) لمعرفة القيم الافتراضية المشتركة،
و[واجهة Python البرمجية](api.md) للاستخدام خارج القوالب.

## مرشحات النص ثنائي الاتجاه { #bidirectional-text-filters }

### `bidi_isolate` { #bidi_isolate }

يحيط القيمة كاملةً بمحارف عزل Unicode. الاتجاه الاختياري هو `"auto"`
أو `"ltr"` أو `"rtl"`؛ وعند حذفه يُستخدم `ISOLATION_DIRECTION` (وقيمته الافتراضية `"auto"`).
استخدم العزل من اليسار إلى اليمين (LTR) للمعرّفات التي لا يُفسَّر محتواها:

```django
{{ book.isbn|bidi_isolate:"ltr" }}
```

تُعرض `None` والنصوص الفارغة كمخرجات فارغة. تُهرَّب شيفرة HTML العادية عند تفعيل
التهريب التلقائي؛ أما شيفرة HTML المعلَّمة مسبقًا بأنها آمنة فيُوثق بها. يعطّل
`{% autoescape off %}` التهريب. يضيف العزل محارف Unicode، لا عنصر HTML، ويزيل أي
محارف `Bidi_Control` موجودة في Unicode من داخل القيمة قبل إحاطتها (ويعيد مخرجات
فارغة إذا لم تحتوِ إلا على محارف تحكم في الاتجاه).

### `bidi_runs` { #bidi_runs }

يعزل فقط المقاطع المضمّنة ذات الاتجاه المعاكس في النص النثري. الاتجاه الأساسي
الاختياري هو `"ltr"` أو `"rtl"`؛ وعند حذفه يتبع اللغة النشطة، لا
`ISOLATION_DIRECTION`. لسلسلة نصية من السياق مثل `note = "مرحبا v1.0"`:

```django
{{ note|bidi_runs:"rtl" }}
```

في النصوص النثرية من اليمين إلى اليسار (RTL)، تُعزل أيضًا الأرقام التي تتخللها علامات
ترقيم، مثل التواريخ والإصدارات؛ أما الأرقام المجردة فتُترك كما هي. في النصوص العادية،
تُزال محارف `Bidi_Control` الموجودة في Unicode قبل فحص المقاطع، ويسبق العزلُ التهريبَ
لتبقى كيانات HTML سليمة. تُعاد السلاسل النصية المعلَّمة مسبقًا بأنها آمنة والكائنات
التي توفّر `__html__` دون تغيير لتجنب إتلاف شيفرة HTML. عند توضيح عزل المقاطع، استخدم
سلسلة نصية عادية من السياق، لا قيمة نصية حرفية آمنة في القالب. تُعرض `None` كمخرجات فارغة.

### `bidi_strip` { #bidi_strip }

يزيل جميع محارف `Bidi_Control` الاثني عشر في Unicode (`ALM` و`LRM` و`RLM` و`LRE`
و`RLE` و`PDF` و`LRO` و`RLO` و`LRI` و`RLI` و`FSI` و`PDI`):

```django
{{ reference|bidi_isolate:"ltr"|bidi_strip }}
```

تُعرض `None` كمخرجات فارغة. يزيل هذا المرشح محارف التحكم ثنائية الاتجاه في Unicode
فقط، وليس أداة لتنقية HTML. تُحفظ حالة المدخلات المعلَّمة بأنها آمنة.

### `bidi_dir` { #bidi_dir }

يعيد `"rtl"` أو `"ltr"` بناءً على أول محرف ذي اتجاه قوي. الاتجاه البديل الاختياري
هو `"ltr"` افتراضيًا؛ وتستخدمه الأرقام وعلامات الترقيم والنصوص الفارغة و`None`:

```django
<span dir="{{ reference|bidi_dir:"rtl" }}">{{ reference }}</span>
```

لا يُتحقق من صحة الاتجاه البديل؛ استخدم `"ltr"` أو `"rtl"`. هذا هو اتجاه المحتوى،
لا اتجاه اللغة النشطة.

## مرشحات التنسيق حسب الإعدادات المحلية { #locale-aware-formatting-filters }

تستخدم هذه المرشحات اللغة النشطة و`NUMERALS` و`USE_BABEL`. لاختيار لغة لكتلة،
حمّل `i18n` أيضًا واستخدم وسم Django المسمّى `{% language %}`.
لا يضيف التنسيق بحد ذاته محارف عزل Unicode؛ أتبعه بالمرشح `bidi_isolate` عند الحاجة.
وكمرشحات Django المضمّنة، تتعامل هذه المرشحات مع الإخفاق دون إثارة استثناءات:
تعيد المرشحات العددية المدخلات غير العددية أو غير المنتهية كنص، وتُعرض التواريخ
والأوقات غير الصالحة كمخرجات فارغة، ويُتجاهل وسيط المنازل العشرية غير السليم.
تُطبَّع السلاسل النصية العددية قبل التنسيق، بما فيها الصيغة الأسّية والمسافات البيضاء
المحيطة بها. أما دالة Python المساعدة `format_currency()` فهي صارمة، وتثير
`ValueError` للمدخلات غير الفارغة أو غير العددية أو غير المنتهية.

### `l10n_number` { #l10n_number }

ينسّق عددًا مع تجميع الخانات واستخدام أرقام الإعدادات المحلية. يحدد الوسيط الاختياري
عدد المنازل العشرية؛ وعند حذفه يُترك تحديد الدقة للآلية الخلفية:

```django
{{ amount|l10n_number:"2" }}
```

عندما تكون `amount = 2.5` واللغة هي الإنجليزية، يُعرض `2.50`. يُتجاهل وسيط الدقة
غير الفارغ إذا لم يكن عددًا صحيحًا. تُعرض `None` أو المدخلات الفارغة كمخرجات فارغة.
يمر النص غير العددي دون تغيير. لا يتيح هذا المرشح وسيطًا للتحكم في تجميع الخانات.

### `l10n_currency` { #l10n_currency }

ينسّق مبلغًا ماليًا باستخدام رمز عملة اختياري؛ والقيمة الافتراضية هي `CURRENCY` (`"USD"`):

```django
{{ book.price|l10n_currency:"EGP" }}
```

يوفّر Babel أنماطًا خاصة بالإعدادات المحلية. تتكون المخرجات البديلة من عدد منسّق
حسب الإعدادات المحلية بمنزلتين عشريتين، ومسافة غير قابلة للكسر، ورمز العملة.
تُعرض `None` أو المدخلات الفارغة كمخرجات فارغة؛ ويستخدم وسيط العملة الفارغ القيمة
الافتراضية المحددة في الإعدادات. تُعرض المدخلات غير العددية دون تغيير بدلًا من إنتاج مبلغ مشوَّه.

### `l10n_percent` { #l10n_percent }

ينسّق نسبةً على هيئة نسبة مئوية، دون وسيط للمرشح:

```django
{{ ratio|l10n_percent }}
```

عندما تكون `ratio = 0.256`، تبدأ المخرجات الإنجليزية بـ`26`. تكون المدخلات عادةً
نسبة ضمن المجال `0..1`، لكن هذا المجال غير مفروض. تضرب آلية Django البديلة القيمة
في 100، وتقرّب إلى عدد صحيح مع تقريب أنصاف الوحدات إلى الأعلى، ثم تلحق `%`.
تُعرض المدخلات الفارغة كمخرجات فارغة؛ وتُعرض المدخلات غير العددية دون تغيير.

### `l10n_timedelta` { #l10n_timedelta }

ينسّق مدة زمنية تُمرَّر ككائن `timedelta` أو كعدد من الثواني. يحدد الوسيط
الاختياري أصغر وحدة، وقيمته الافتراضية `"second"`:

```django
{{ elapsed|l10n_timedelta }}
```

يوفّر Babel أنماط الوحدات وصياغة الاتجاه وفق CLDR. ودون Babel، تُستخدم سلاسل
الوحدات المترجمة في `timesince` من Django، بما في ذلك صيغ الثواني المترجمة
للإعدادات المحلية المرفقة؛ وتستخدم العربية صياغة الحزمة نفسها للوحدات والاتجاه،
فلا يسبق المفرد والمثنى رقم (`ثانيتان`، `خلال ثانيتين`). تتبع الأرقام الإعداد `NUMERALS` واللغة النشطة.
تُعرض `None` والمدخلات الفارغة كمخرجات فارغة؛ وتمر المدخلات غير العددية أو
غير المنتهية كنص دون تغيير.

### `l10n_timesince` { #l10n_timesince }

يعرض تاريخًا أو تاريخًا ووقتًا بالنسبة إلى الآن، مع صياغة للماضي والمستقبل:

```django
{{ book.published_on|l10n_timesince }}
```

تُقاس التواريخ بأيام كاملة؛ وتُقاس قيم التاريخ والوقت بالنسبة إلى الوقت الحالي.
يسجّل المرشح `expects_localtime=True`، فتتبع قيم التاريخ والوقت المرتبطة بمنطقة
زمنية المنطقة الزمنية النشطة في Django و`{% localtime off %}`. تُعرض `None`
والقيم غير الصالحة كمخرجات فارغة.

### `l10n_filesize` { #l10n_filesize }

ينسّق عددًا من البايتات بأرقام حسب الإعدادات المحلية ووسيط اختياري للنظام الثنائي:

```django
{{ upload.size|l10n_filesize }}
```

يستخدم الوضع الافتراضي قوى العدد 1000؛ ومرّر `"binary"` لأحجام بخطوات 1024
مع تسميات Django مثل `KB` و`MB` وما بعدهما. لا تختار الأحجام الثنائية إلا
القيمة `True` والسلاسل `"1"` و`"true"` و`"yes"` و`"binary"` (دون حساسية
لحالة الأحرف)؛ ويستخدم أي شيء آخر الخطوات العشرية. تأتي أسماء الوحدات من
فهارس الحزمة للغات الست المرفقة، تحت سياق خاص بها حتى لا يتغير ناتج
`filesizeformat` في Django نفسه، ومن ترجمات Django لغيرها. تستخدم الأحجام
السالبة علامة الطرح الخاصة بالإعدادات المحلية. تُعرض `None` والمدخلات الفارغة
كمخرجات فارغة؛ وتمر المدخلات غير العددية أو غير المنتهية كنص دون تغيير.

### `l10n_date` { #l10n_date }

ينسّق تاريخًا. القيمة الافتراضية لنمط التنسيق الاختياري هي `"medium"`:

```django
{{ book.published_on|l10n_date:"long" }}
```

استخدم `"short"` أو `"medium"` أو `"long"` أو `"full"`. تعتمد الأنماط المخصصة
على الآلية الخلفية. تُعرض `None` وقيم التاريخ غير الصالحة كمخرجات فارغة؛ وتتبع
أشكال الأرقام المحلية الإعداد `NUMERALS`.

### `l10n_datetime` { #l10n_datetime }

ينسّق تاريخًا ووقتًا. القيمة الافتراضية لنمط التنسيق الاختياري هي `"medium"`:

```django
{{ updated_at|l10n_datetime:"short" }}
```

تطابق الأنماط وسلوك الأنماط المخصصة ما يقدمه `l10n_date`. تُعرض `None` وقيم
التاريخ والوقت غير الصالحة كمخرجات فارغة. يُسجَّل كل من `l10n_datetime` و`l10n_time`
مع `expects_localtime=True`، ولذلك يحوّل Django قيم `datetime` المرتبطة بمنطقة زمنية
إلى المنطقة الزمنية النشطة عند تفعيل `USE_TZ`، ويتركها كما هي داخل
`{% localtime off %}` (أو عندما تكون `USE_TZ=False`).

### `l10n_time` { #l10n_time }

ينسّق وقتًا أو تاريخًا ووقتًا. القيمة الافتراضية لنمط التنسيق الاختياري هي `"medium"`:

```django
{{ opening_time|l10n_time:"short" }}
```

دون Babel، تستخدم الأنماط الأربعة المسمّاة تنسيق `TIME_FORMAT` الخاص باللغة.
لإظهار الثواني صراحةً، مرّر سلسلة تنسيق مخصصة بصيغة Django مثل `H:i:s`.
أما Babel فيستمر في استخدام أنماطه المسمّاة وأنماط CLDR المخصصة.
تُعرض `None` وقيم الوقت غير الصالحة كمخرجات فارغة.

### `hijri_date` { #hijri_date }

ينسّق تاريخًا أو تاريخًا ووقتًا بالتقويم الهجري (أم القرى). نمط التنسيق الاختياري هو
`"long"` (الافتراضي) أو `"medium"` أو `"short"`:

```django
{{ book.published_on|hijri_date }}
{{ book.published_on|hijri_date:"short" }}
```

تتبع أسماء الأشهر لغة الواجهة الحالية (العربية أو الفارسية أو الأردية أو كتابة
لاتينية بالإنجليزية)، وتتبع الأرقام الإعداد `NUMERALS`، وتُضاف لاحقة التقويم الهجري.
تُحوَّل قيم التاريخ والوقت المرتبطة بمنطقة زمنية إلى المنطقة الزمنية الحالية أولًا.
تُعرض `None` والقيم التي ليست تواريخ والتواريخ خارج المدى 1343–1500 هـ فارغةً،
ويُستخدم `"long"` إذا مُرِّر نمط غير معروف. راجع [`format_hijri_date`](api.md) لدالة بايثون.

### `local_digits` { #local_digits }

يعيد كتابة أشكال الأرقام في سلسلة نصية منسّقة مسبقًا، دون تغيير علامات الترقيم:

```django
{{ "REF-2024"|local_digits }}
```

عند استخدام الأرقام التلقائية في `ar-eg`، يُعرض `REF-٢٠٢٤`. يتعرف التحويل على
الأرقام اللاتينية والعربية الهندية والعربية الهندية الموسّعة في المدخلات.
تُعرض `None` كمخرجات فارغة؛ ويمر النص غير العددي دون تغيير، وكذلك القيمة الأصلية إذا فشل التحويل.

### `phone_display` { #phone_display }

ينسّق رقم هاتف بصيغة E.164 مجمّعًا بحسب الدولة ومحاطًا بعزل Unicode من اليسار
إلى اليمين (`U+2066` ... `U+2069`) حتى تبقى علامة `+` البادئة ومجموعات الأرقام
بترتيبها الصحيح داخل النص العربي:

```django
{{ customer.phone|phone_display }}
{{ local_phone|phone_display:"SA" }}
```

يعرض الرقم `"+966501234567"` على النحو `⁦+966 50 123 4567⁩`. يغطي التجميع
المضمّن السعودية (`SA`) والإمارات (`AE`) والكويت (`KW`) وقطر (`QA`) والبحرين
(`BH`) وعُمان (`OM`) ومصر (`EG`) والأردن (`JO`)، ويفوّض التنسيق إلى حزمة
`phonenumbers` الاختيارية عند تثبيتها. يمكن تمرير رمز منطقة اختياري لتطبيع
الأرقام المحلية قبل تجميعها. تُعرض `None` والمدخلات الفارغة كمخرجات فارغة؛ أما
النصوص غير المعروفة فتُهرَّب عند تفعيل التهريب التلقائي وتُعاد محاطةً بعزل LTR.
راجع [أرقام الهاتف](api.md#phone-numbers) للتعرف على `normalize_phone()`
و`validate_phone()` و`format_phone_display()` و`PhoneNumberField`.

### `ordinal_ar` { #ordinal_ar }

يكتب العدد الصحيح الموجب عددًا ترتيبيًا بالعربية. يحدد الوسيط الاختياري جنس
الاسم الذي يصفه العدد وتعريفه أو تنكيره:

```django
{{ floor.number|ordinal_ar }}
{{ invoice.sequence|ordinal_ar:"f" }}
{{ step.position|ordinal_ar:"f,indef" }}
```

للقيمة `3` تُعرض `الثالث` و`الثالثة` و`ثالثة`. الوسيط قائمة تفصل بين عناصرها
فاصلة، بأي ترتيب، وتضم الجنس (`"m"` أو `"f"`، وكذلك `"masculine"` و`"feminine"`)
والتعريف أو التنكير (`"def"` أو `"indef"`، وكذلك `"definite"` و`"indefinite"`)؛
والافتراضي هو المذكر المعرّف. وبخلاف بقية مرشحات هذا القسم، تبقى الألفاظ عربية
أيًّا كانت اللغة النشطة. تُكتب الألفاظ في حالة الرفع وتغطي القيم من 1 إلى
999,999,999,999؛ ويُكتب ما زاد على 100 بالعدد الأصلي لمئاته وما فوقها متبوعًا
بالعدد الترتيبي لخانتيه الأخيرتين (`المئة والخامس والعشرون` للعدد 125). تُعرض
`None` والمدخلات الفارغة كمخرجات فارغة. أما القيمة التي ليست عددًا صحيحًا
موجبًا، وأي قيمة يرافقها وسيط غير معروف، فتُعاد كما هي وتُهرَّب عند تفعيل
التهريب التلقائي. راجع [الأعداد الترتيبية العربية](api.md#arabic-ordinals)
لمعرفة الصيغ والدالة `ordinal_words()`.

### `ordinal_short` { #ordinal_short }

يكتب العدد الصحيح الموجب بالصيغة الترتيبية المختصرة في اللغة النشطة:

```django
{{ ranking.position|ordinal_short }}
```

للقيمة `3` يُعرض `3rd` في الإنجليزية و`الـ3` في العربية. تضيف الإنجليزية إحدى
اللواحق `st` أو `nd` أو `rd` أو `th`، وتسبق العربيةُ الأرقامَ بأداة التعريف
متبوعةً بتطويل، أي `الـ`، وتحصل اللغات الأخرى على الأرقام وحدها. تبقى الأرقام
لاتينية ما لم يُفعَّل `LOCALIZE_CHANGELIST_DIGITS`؛ وعندئذٍ تتبع اللغة النشطة
والإعداد `NUMERALS`، فيُعرض `الـ٣` في `ar-eg`. لا يقبل المرشح أي وسيط. تُعرض
`None` والمدخلات الفارغة كمخرجات فارغة؛ أما القيمة التي ليست عددًا صحيحًا موجبًا
فتُعاد كما هي
وتُهرَّب عند تفعيل التهريب التلقائي. راجع
[`ordinal_short()`](api.md#arabic-ordinals) لدالة Python المساعدة.

### الفروق بين الآليات الخلفية { #backend-differences }

عند غياب Babel أو ضبط `USE_BABEL=False`، تقرأ مرشحات التاريخ والوقت وحدات التنسيق الخاصة
باللغة النشطة. لوحدات المشروع المحددة في `FORMAT_MODULE_PATH` الأولوية على وحدات
Django المضمّنة. للتاريخ وحده أو مع الوقت، يختار النمط `"short"` التنسيق المختصر،
بينما تختار الأنماط `"medium"` و`"long"` و`"full"` التنسيق المعتاد. إذا لم تحدد
أي وحدة محلية `DATETIME_FORMAT`، تجمع المرشحات بين `DATE_FORMAT` و`TIME_FORMAT`؛
وعند غياب `SHORT_DATETIME_FORMAT`، تجمع بين `SHORT_DATE_FORMAT` و`TIME_FORMAT`.
توفّر الحزمة أنماطًا مشتقة من CLDR للأردية (`ur`)، وكذلك للأويغورية (`ug`) في
Django 4.2 الذي لا يتضمّن وحدة تنسيق لهذه اللغة.

تُكتب الأنماط المخصصة بصيغة Django عند استخدام الآلية البديلة، وبصيغة CLDR عند
استخدام Babel. وفي الحالتين تظل أشكال الأرقام خاضعة للإعداد `NUMERALS`. لا تقبل
هذه المرشحات وسيطًا للغة أو المنطقة الزمنية أو نظام الترقيم؛ استخدم الإعدادات أو
تفعيل اللغة أو [واجهة التنسيق البرمجية في Python](api.md) حسب الحاجة.

## مرشّحات الكتابة بالحروف العربية { #arabic-wording-filters }

### `arabic_words` { #arabic_words }

يكتب عددًا صحيحًا بالحروف العربية، سواء أكان المدخل عددًا أم نصًّا عدديًّا
قيمته عدد صحيح. يحدّد الوسيط الاختياري جنس الاسم المعدود، وقيمته الافتراضية
`"masculine"` للمذكّر.

```django
{{ 3|arabic_words }}
{{ 3|arabic_words:"feminine" }}
```

الناتج هو «ثلاثة» و«ثلاث» على الترتيب. يُعرض نص فارغ عند إدخال قيمة غير
صالحة أو جنس غير معروف. لكتابة عدد ترتيبي، استخدم
[واجهة Python البرمجية](api.md#arabic-words).

### `amount_in_words` { #amount_in_words }

يكتب إجمالي المبلغ بالحروف العربية ويختمه بكلمة «فقط». عند حذف وسيط العملة
يُستخدم `"SAR"`، بصرف النظر عن الإعداد `CURRENCY` أو اللغة النشطة. مثال:

```django
{{ "٢٫٠٥"|amount_in_words:"SAR" }}
{{ "١١٫٠٢"|amount_in_words:"EGP" }}
```

الناتج هو «ريالان اثنان وخمس هللات فقط» و«أحد عشر جنيهًا وقرشان اثنان فقط».
يُعرض نص فارغ عند إدخال مبلغ غير صالح أو عملة غير معروفة. راجع
[واجهة Python البرمجية](api.md#arabic-words) لمعرفة العملات المدعومة وقواعد
التقريب وطريقة تخصيص الصياغة.

## وسوم الاتجاه والملفات الثابتة { #direction-and-asset-tags }

جميع الوسوم، باستثناء `rtl_admin_language_switcher`، وسوم بسيطة وتدعم
`as variable` لحفظ نتيجتها. تتلقى الوسوم التي تستخدم السياق هذا السياق تلقائيًا؛
لا تمرّره كوسيط في القالب.

### `rtl_admin_direction` { #rtl_admin_direction }

يعيد `"rtl"` أو `"ltr"` للغة النشطة، بما في ذلك اللغات الإضافية المكتوبة من اليمين إلى اليسار:

```django
<section dir="{% rtl_admin_direction %}">{{ content }}</section>
```

### `rtl_admin_body_class` { #rtl_admin_body_class }

يعيد فئات عنصر body الخاصة بورقة الأنماط:

```django
<body class="{% rtl_admin_body_class %}">
  {{ content }}
</body>
```

تبدأ النتيجة بـ`rtl-admin rtl-admin--rtl` أو `rtl-admin rtl-admin--ltr`.
تليها فئات تعتمد على الإصدار، في كلا اتجاهَي الواجهة:

- تُضاف `rtl-admin--pre-6-0` فقط قبل Django 6.0، لتخطيط أدوات الكائنات القديم
  الذي يعتمد على التعويم.
- تُضاف `rtl-admin--pre-6-1` فقط قبل Django 6.1، لهوامش التاريخ والوقت القديمة
  وحشوة نصوص المساعدة في النماذج المحاذاة.

لذلك يحصل Django 5.2 على الفئتين، ويحصل Django 6.0 على `rtl-admin--pre-6-1` وحدها،
ولا يحصل Django 6.1 أو أحدث على أيٍّ منهما. ثم يتضمن الوسم
`rtl-admin--isolate-cells` و`rtl-admin--plaintext-fields` عند تفعيل إعداداتهما.
تُخرج جميع هذه الفئات حتى لو كانت `ENABLE_CSS=False`.

### `rtl_admin_site_name_tag` { #rtl_admin_site_name_tag }

يعيد اسم عنصر الهوية: `h1` قبل Django 5.0، و`div` في الإصدارات الأخرى:

```django
{% rtl_admin_site_name_tag as site_name_tag %}
<{{ site_name_tag }} id="site-name">{{ site_header }}</{{ site_name_tag }}>
```

### `rtl_admin_styles` { #rtl_admin_styles }

يُخرج رابط ورقة الأنماط وأي تخصيص للإعداد `FONT_STACK`:

```django
{% rtl_admin_styles %}
```

تكون المخرجات فارغة عند `ENABLE_CSS=False`. تستخدم عناوين URL معالجة Django
للملفات الثابتة. تُضاف قيمة `csp_nonce` الموفَّرة في السياق إلى عنصر الرابط ووسم
الأنماط الاختياري. تُحوَّل قائمة الخطوط إلى صيغة CSS، ولا تُهرَّب بصيغة HTML؛ راجع
[الإعدادات](configuration.md#styling-and-direction) لمعرفة قواعد علامات الاقتباس
والقيم التي تُتجاوز.

### `rtl_admin_print_styles` { #rtl_admin_print_styles }

يُخرج رابط ورقة أنماط الطباعة بالسمة `media="print"`:

```django
{% rtl_admin_print_styles %}
```

تكون المخرجات فارغة عند `PRINT_STYLES=False`. تستخدم عناوين URL معالجة Django
للملفات الثابتة، وتُضاف قيمة `csp_nonce` الموفَّرة في السياق إلى عنصر الرابط.
راجع [الإعدادات](configuration.md#printing) لمعرفة العناصر التي تخفيها ورقة
أنماط الطباعة والعناصر التي تحافظ عليها.

### `rtl_admin_scripts` { #rtl_admin_scripts }

يُخرج سكربت مبدّل اللغة المؤجَّل التنفيذ:

```django
{% rtl_admin_scripts %}
```

تكون المخرجات فارغة عند `LANGUAGE_SWITCHER=False`؛ وإلا فقد تظهر حتى عندما يكون
النموذج مخفيًا بسبب عدد اللغات أو غياب عنوان URL. يستخدم الوسم أيضًا `csp_nonce`
من السياق عند توفره. لا تنشئ الحزمة قيم nonce.

يستدعي القالب الأساسي للوحة الإدارة المرفق مع الحزمة بالفعل وسوم فئات body والأنماط
والسكربت والهوية. استخدم هذه الوسوم منفردةً في القوالب المخصصة بدلًا من تحميل
الملفات مرتين. راجع [التثبيت](installation.md) لمعرفة وراثة القوالب.

## وسوم اللغة والمجموعات { #language-and-collection-tags }

### `rtl_admin_language_switcher` { #rtl_admin_language_switcher }

يعرض نموذج مبدّل اللغة:

```django
{% rtl_admin_language_switcher %}
```

لا يدعم وسم التضمين هذا صيغة `as variable`. لا يعرض شيئًا عند تعطيله، أو عند وجود
أقل من صفَّين للغات، أو عندما يثير توليد عنوان `set_language` الاستثناء
`NoReverseMatch`. لا يؤدي غياب `LocaleMiddleware` إلى إخفاء النموذج.

يرسل النموذج طلب POST يتضمن `language` المختارة ورمز CSRF و`next` إلى `set_language`.
تحتوي `next` على المسار الكامل للطلب الحالي، بما في ذلك سلسلة معاملات الاستعلام،
أو تكون فارغة عند غياب الطلب. استخدم سياق قالب عاديًا يدعم الطلب وCSRF.
ترسل JavaScript النموذج عند تغيير الاختيار وتخفي الزر؛ ودونها يعمل زر الإرسال.
راجع [البدء السريع](quick-start.md) و[فحوصات النظام](system-checks.md).

### `rtl_admin_language_links` { #rtl_admin_language_links }

يعيد بيانات مجردة لاستخدامها في شيفرة HTML مخصصة، لا روابط تشعبية جاهزة:

```django
{% rtl_admin_language_links as languages %}
<ul>
  {% for language in languages %}
    <li lang="{{ language.code }}"
        dir="{% if language.bidi %}rtl{% else %}ltr{% endif %}">
      {{ language.label }}{% if language.is_active %} — active{% endif %}
    </li>
  {% endfor %}
</ul>
```

يحتوي كل قاموس على `code` و`label` و`bidi` و`is_active`؛ ولا يوجد مفتاح لعنوان URL.
يعيد الوسم البيانات حتى عند تعطيل المبدّل أو غياب نقطة نهايته. تُحدَّد اللغة النشطة
بمقارنة الرموز بعد تحويلها إلى أحرف صغيرة مقارنةً تامة، دون الرجوع إلى رمز بديل
للمنطقة. يُحفظ ترتيب اللغات وتكرارها. راجع [الإعدادات](configuration.md)
لمعرفة أنماط تسميات اللغات ومصدر قائمة اللغات.

### `rtl_admin_isolated_join` { #rtl_admin_isolated_join }

يدمج عناصر كائن قابل للتكرار، مع عزل كل قيمة باستخدام `ISOLATION_DIRECTION`:

```django
{% rtl_admin_isolated_join references "; " %}
```

على سبيل المثال، يمكن أن تكون `references` هي `["ISBN-123", "REF-456"]`.
القيمة الافتراضية للفاصل الاختياري هي `", "`. يُعرض الكائن القابل للتكرار الفارغ
أو `None` كمخرجات فارغة؛ مرّر مجموعةً، لا سلسلة نصية، إلا إذا كنت تقصد دمج المحارف
منفردةً. تُهرَّب القيم والفواصل العادية، بينما يُوثق بشيفرة HTML الآمنة. يظل تهريب
القيم مفعّلًا حتى داخل `{% autoescape off %}`. ولا يُعزل الفاصل نفسه.
